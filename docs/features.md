# 기능 정의서 (Feature Specification)

> **범위**: 사내 ERP — 인증·인사·근태·휴가 모듈 (MVP)
> **작성일**: 2026-05-30
> **개정일**: 2026-06-03 (근태·결재·휴가 도메인 및 3단계 권한 반영)
> **참조 문서**: requirements.md (요구사항 정의서)

## 1. 인증

| 기능 ID | 기능명 | 기능 설명 | 접근 권한 | 개발 우선순위 | 요구사항 근거 |
|--------|--------|---------|---------|-------------|-----------|
| FEAT-AUTH-01 | 로그인 | 사번·비밀번호로 인증, 비활성(is_active=false) 계정 거부, 성공 시 HttpOnly 세션 쿠키 발급. 반복 로그인 실패 시 Supabase Auth rate limit 정책에 따라 일시 차단되며 안내를 로그인 화면에 표시 | 전체 | P0 | AUTH-1 |
| FEAT-AUTH-02 | 로그아웃 | 서버 세션 무효화 + 세션 쿠키 삭제 | 로그인 사용자 | P0 | AUTH-2 |

> **세션 정책 (AUTH-3)**: 미동작 1시간(idle) 또는 로그인 후 8시간(absolute) 경과 시 세션이 자동 만료되어 재인증을 요구한다. 사용자가 수행하는 기능이 아니라 로그인 세션에 적용되는 인증 공통 정책이다.

## 5. 직원 정보 관리·조회

| 기능 ID | 기능명 | 기능 설명 | 접근 권한 | 개발 우선순위 | 요구사항 근거 |
|--------|--------|---------|---------|-------------|-----------|
| FEAT-EMP-01 | 직원 등록 | 인사 프로필 등록(필수값·형식 검증), 부서·직급은 코드에서 선택, 사번 자동 채번(입사연도+순번, 예: 2026-0001, 전체 유일), 로그인 계정 자동 생성 연동. 등록 시 연차 잔액 레코드 초기화 + 입사일 기준 자동 적립 스케줄 시작(FEAT-LEAVE-03·04) | 관리자 | P0 | HR-5, ACCT-2 |
| FEAT-EMP-02 | 직원 정보 수정 | 등록된 직원 인사정보 수정(사번 불변, 부서·직급은 코드에서 선택). 부서 이동 시 결재선은 이후 신규 결재부터 새 부서 기준 적용, 진행 중 대기 결재는 기존 지정 승인자가 처리 | 관리자 | P0 | HR-6 |
| FEAT-EMP-03 | 퇴사 처리 | 재직→퇴사 상태 변경, 계정 비활성화 연동, 인사 이력 보존, 복직 불가(비가역). 퇴사 시 본인이 올린 대기 결재·휴가는 자동 취소, 본인이 승인자인 대기 결재는 재배정(FEAT-APPR-06) | 관리자 | P1 | HR-7 |
| FEAT-EMP-04 | 직원 목록 조회 | 전체 직원 목록 조회(무한 스크롤 — 최초 20건 로드, 목록 하단 도달 시 다음 20건 점진 로드) | 관리자 | P0 | HR-8 |
| FEAT-EMP-05 | 직원 검색·필터 | 이름·사번·부서·재직상태 기준 검색/필터 | 관리자 | P1 | HR-9 |

| FEAT-EMP-07 | 내 인사정보 조회 | 본인 기본 인사정보 조회(읽기 전용, 수정 불가) | 본인 | P0 | HR-11 |

> **목록 표시 정책 (공통)**: 관리자 목록 화면(직원 관리·계정 관리·공통 코드)은 페이지 번호 방식 대신 **무한 스크롤**로 표시한다. 최초 진입 시 20건을 로드하고, 스크롤이 목록 하단에 도달하면 다음 20건을 이어서 로드한다(IntersectionObserver 기반). 공통 코드는 전체를 받아 클라이언트에서 20건 단위로 점진 노출한다. 근태·휴가·결재함 목록(§6·§7·§8)도 동일 정책을 따른다.

> **표준 근무시간 정의**: 09:00~18:00, 점심 휴게 12:00~13:00(1시간), 소정근로 8시간. 근태 자동판정(FEAT-ATT-03)·근무시간 집계(FEAT-ATT-10)·만근 판정(FEAT-LEAVE-02)은 모두 실근무(휴게 제외)·KST 기준이며, 소정근로일은 평일(월~금) 중 공휴일(FEAT-ATT-11)을 제외한 날이다.

## 7. 결재

> 근태 보정(FEAT-ATT-07~09)과 휴가 신청(FEAT-LEAVE-06)이 공유하는 공통 전자결재 기능. 신청자가 지정한 승인자(같은 부서의 부서 관리자 MANAGER)의 결재함을 통해 승인/반려된다.

| 기능 ID | 기능명 | 기능 설명 | 접근 권한 | 개발 우선순위 | 요구사항 근거 |
|--------|--------|---------|---------|-------------|-----------|
| FEAT-APPR-01 | 승인자 지정 | 신청 시 같은 부서의 부서 관리자(본인 제외) 1명을 승인자로 지정, 없으면 전사 관리자(ADMIN)로 후보 확대, 그래도 없으면 신청 불가 안내 | 본인 | P1 | APPR-1 |
| FEAT-APPR-02 | 결재함 조회 | 승인자가 본인에게 배정된 대기 결재(근태 보정·휴가) 목록 조회(무한 스크롤) | 승인자 | P1 | APPR-2 |
| FEAT-APPR-03 | 결재 승인 | 대기 결재를 승인. 근태 보정은 대상 기록에 반영(FEAT-ATT-09), 휴가는 신청 시 차감(FEAT-LEAVE-10)된 잔액 확정 처리 및 휴가-근태 연동(FEAT-LEAVE-11) | 승인자 | P1 | APPR-3 |
| FEAT-APPR-04 | 결재 반려 | 대기 결재를 반려(반려 사유 기록). 휴가는 신청 시 차감된 잔액 복원(FEAT-LEAVE-10) 후 종결, 근태 보정은 대상 기록 변경 없이 종결 | 승인자 | P1 | APPR-4 |
| FEAT-APPR-05 | 내 결재 요청 현황 | 신청자가 본인이 올린 요청의 상태(대기/승인/반려/취소)와 처리 결과 조회, 반려된 요청은 수정하여 재신청 가능 | 본인 | P1 | APPR-5 |
| FEAT-APPR-06 | 승인자 재배정 | 지정 승인자가 퇴사·비활성·부재로 처리할 수 없을 때 같은 부서의 다른 부서 관리자에게 재배정(없으면 전사 관리자로 확대) | 본인·관리자 | P1 | APPR-6 |
| FEAT-APPR-07 | 결재 알림 | 승인자에게 대기 결재 건수를, 신청자에게 승인·반려·재배정 결과를 시스템 화면에 표시(미확인 표시 포함) | 시스템(자동) | P1 | APPR-7 |

> **결재 상태 흐름**: `대기(pending) → 승인(approved) | 반려(rejected) | 취소(cancelled)`. 승인·반려·취소는 종결 상태로 되돌릴 수 없다. 취소는 신청자가 승인 전에 가능하며, 휴가는 승인 후에도 휴가 시작일 이전이면 신청자가 취소할 수 있고 차감 잔액은 자동 환원된다(FEAT-LEAVE-07).

> **휴가 종류 기본 시드 (LEAVE-1)**: 초기 배포 시 연차·오전반차·오후반차·병가·경조사·예비군·민방위·병역판정검사·출산전후휴가·배우자출산휴가·난임치료휴가·가족돌봄휴가·육아휴직 등을 기본 휴가 종류로 등록한다(관리자가 FEAT-LEAVE-01로 가감 가능).

> **증빙 정책 (requirements §9-4)**: 본인 재량으로 쓰는 휴가(연차·반차·생리휴가·가족돌봄휴가·선거 투표)는 증빙 불요, 외부 사건을 사유로 하는 휴가(출산전후·유산사산·배우자출산·난임치료·육아, 예비군·민방위·병역판정검사·공의 직무, 경조사·병가·산재 요양)는 증빙 필수가 권장 기본값이다. 증빙 필요=참이면 휴가 신청(FEAT-LEAVE-06) 시 파일 1건(PDF·JPG·PNG, 최대 10MB) 첨부가 필수이며 미첨부 시 제출 차단. 첨부는 신청자 본인과 지정 결재자만 열람(민감정보 보호)하며 퇴사 후 3년간 보관한다.

> **일수 한도 (requirements §9-5)**: 법정 휴가는 법정 일수(연차 1년 미만 월 1일·최대 11일 / 1년 이상 15일, 출산전후 90일, 배우자출산 20일, 난임치료 연 6일, 가족돌봄 연 10일 등), 경조사·병가는 회사 정책 일수를 적용한다(FEAT-LEAVE-01의 `한도 일수` 시드값, 관리자 조정 가능).
